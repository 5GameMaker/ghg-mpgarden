# Garden game

Multiplayer test with easily hackable data.

If webxdc is not available, will attempt to use AMX (not included with webxdc), though beware of abuse
if you send the room ID in public chat.

## Building

No need. It's already "built".

Do `$ python -m http.server` and open the displayed link in the browser.

`$ ./build.sh` builds a .xdc file to paste in DeltaChat, `$ ./test.sh` does that and also launches it in
a webxdc environment.
